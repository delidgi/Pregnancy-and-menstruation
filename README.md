# Reproductive System — SillyTavern Extension

Расширение добавляет реалистичную репродуктивную систему в RP: менструальный цикл, зачатие через dice-roll, отслеживание беременности по RP-датам, осложнения, визиты к врачу, роды.

## Установка

https://github.com/delidgi/Pregnancy-and-menstruation

Перезапустите SillyTavern. Расширение появится в панели расширений.

## Как работает

### Менструальный цикл
- 28-дневный цикл с четырьмя фазами: менструация (1-5), фолликулярная (6-11), овуляция (12-16), лютеиновая (17-28)
- День цикла синхронизируется с AI через парсинг текста или авто-продвижение по реальному времени
- Фаза цикла влияет на шанс зачатия: овуляция — x1.65, остальные фазы — x0.25-0.5

### Зачатие (dice-roll)
AI ставит тег `<!-- [CYCLE_DAY:14][CONCEPTION_CHECK] -->` в конце сообщения, когда происходит вагинальная эякуляция внутрь. Расширение:

1. Валидирует контекст (отсекает анальный, оральный секс, будущее время, прерванный акт)
2. Бросает dice: базовый шанс 20% × модификатор фазы цикла
3. Применяет контрацепцию (презерватив 85%, таблетки 91%, ВМС 99%) — с шансом провала
4. При успехе — устанавливает беременность, определяет количество плодов (двойня ~3%, тройня ~0.1%) и пол
5. Инжектирует результат в следующий ответ AI



### Беременность
- Срок считается по RP-датам (парсинг дат из текста AI) относительно даты зачатия
- Настраиваемая длительность: 4-100 недель (по умолчанию 40)
- Промпт-инжекция сообщает AI текущий срок, симптомы, размер плода, ПДР
- UI-панель показывает прогресс-бар, симптомы, рекомендации

### Осложнения
Каждые 7 RP-дней — dice-roll на осложнение. Шанс зависит от триместра и количества плодов:
- 1 триместр (15%): токсикоз, угроза выкидыша, анемия
- 2 триместр (5%): предлежание плаценты, ИЦН, гест. диабет, отслойка
- 3 триместр (12%): гестоз, преждевременные роды, ЗВУР, маловодие

Критические осложнения могут привести к потере беременности (dice-roll на выживание). Кнопка «К врачу» позволяет лечить осложнения (шанс: 75% для warning, 50% для critical), кулдаун 3 RP-дня.

### Роды
AI ставит тег `<!-- [BIRTH] -->` при достижении ≥90% срока. Расширение сбрасывает беременность и показывает уведомление.

## Парсинг RP-дат
Поддерживаемые форматы:
- `Дата: 21 октября 2023` / `Date: 21 October 2023`
- `21.10.2023` / `21/10/23`
- `2023-10-21` (ISO)
- `📅 13/10/23`
- JSON: `date:{"output":"21.10.2023"}`

## Настройки

| Параметр | Описание |
|----------|----------|
| Включено | Вкл/выкл всю систему |
| Уведомления | Показывать нотификации |
| Контрацепция | none / condom (85%) / pill (91%) / iud (99%) |
| День цикла | Ручная установка 1-28 |
| Срок беременности | Длительность в неделях (4-100) |
| Шанс двойни | % (по умолчанию 3) |
| Шанс тройни | % (по умолчанию 0.1) |
| Ручная установка | Установить беременность вручную с указанием срока, количества плодов и RP-даты |

## Архитектура

```
index.js          — точка входа, загрузка, события
config.js         — константы, дефолты, шансы
state.js          — доступ к настройкам и данным беременности (per-chat)
helpers.js        — чистые функции (dice, фазы, симптомы, форматирование)
date-parser.js    — парсинг RP-дат из текста
pregnancy.js      — логика зачатия, осложнений, врача
prompts.js        — инжекция промптов для AI
message-handler.js — обработка входящих сообщений
ui.js             — панель настроек и мониторинг
notifications.js  — кастомные уведомления
```

Данные беременности хранятся per-chat в `extension_settings.reproductive-system.chatPregnancyData[chatId]`.

## Промпт для AI

Расширение инжектирует в чат (depth 0, IN_CHAT):
- Текущий день цикла и фазу
- Инструкцию по тегу `[CONCEPTION_CHECK]` (только если не беременна)
- При беременности: срок, ПДР, симптомы, размер плода, инструкцию по тегу `[BIRTH]`
